# Super Drag Userscript

自用的 Tampermonkey 鼠标拖拽脚本，用于通过鼠标左键拖拽快速处理选中文本、链接和图片。

## 当前版本

- **v3.5.2**
- 主脚本：`super-drag.user.js`

## 主要功能

- 文本拖拽：搜索、打开固定网址、复制文本、生成二维码
- 链接拖拽：打开链接、复制链接、复制链接文字、二维码
- 图片拖拽：以图搜图、保存图片、复制图片/图片链接、打开图片源链接
- 8 方向手势，并支持最多 4 段组合手势
- 中央 HUD 实时显示手势方向和动作
- `Esc` 取消正在进行的拖拽操作
- `Alt + Y` 打开“超级拖拽设置中心”
- 支持站点黑名单
- 支持 JSON 配置导入与备份
- 支持动作使用次数统计
- 单例锁与顶层窗口隔离，减少重复注入和 iframe 干扰
- 二维码流转中心

## 安装

1. 浏览器安装 Tampermonkey。
2. 打开仓库中的 `super-drag.user.js`。
3. 点击 **Raw**，由 Tampermonkey 接管安装。

## 设置

- 快捷键：`Alt + Y`
- Tampermonkey 菜单：**拖拽扩展设置中心**
- `Esc`：关闭设置/二维码窗口，或取消当前拖拽手势

## 说明

本项目主要用于个人日常浏览器工作流。默认搜索规则和快捷动作可在脚本设置中心自行调整。


## 自动更新

主脚本已经配置 GitHub 更新地址：

- `@updateURL` 指向仓库 main 分支的 `super-drag.user.js`
- `@downloadURL` 指向同一 Raw 文件

首次从 GitHub Raw 安装/覆盖后，Tampermonkey 后续可按 `@version` 检查更新。

## SkrBT 兼容

SkrBT 对外部直接打开 `/search?keyword=...` 的访问会回到首页。v3.5.1 起，拖拽到 SkrBT 搜索时会自动：

1. 记录搜索词
2. 打开 `https://skrbtso.cc/`
3. 自动填入网站原生搜索框
4. 自动提交搜索表单

用户操作仍然保持“一次拖拽即可搜索”。


## SkrBT 磁链快捷操作

v3.5.2 起，SkrBT 搜索结果页会在存在站内详情页的资源旁显示：

- **打开**：按需读取该条详情页的磁力链接并交给系统磁力协议
- **复制**：按需读取磁力链接并直接写入剪贴板

实现特点：

- 只在点击按钮时请求当前这一条详情页，不批量抓取
- 同一详情页在当前页面内只请求一次，后续操作直接复用缓存
- 成功反馈直接显示在按钮上（如 `✓ 已复制`），不弹右上角 Toast
- 不限制搜索关键词格式；只要 SkrBT 返回有效资源并带有详情链接，就显示快捷按钮
